# JJYB-YouTube-dl 使用文档

**源码版本：3.4.4（待发布）· 最新正式资产：3.4.3 · 修改日期：2026-11-20。** 基于 [Open Video Downloader / youtube-dl-gui](https://github.com/jely2002/youtube-dl-gui)，通过 yt-dlp 下载媒体与平台字幕，使用 FFmpeg 后处理。仅下载拥有权利或已获授权的内容。

## 获取与启动

- [自有仓库与 Release](https://github.com/jianjieyiban/JJYB-YouTube-dl/releases)，实际公开资产以页面为准。目前最新正式版为 3.4.3，3.4.4 仅为待发布源码；发行范围仅 Windows x64 便携程序，未构建安装器或验证其他系统。
- 保留主程序同目录的 `jjyb-portable` 和随附资源，在可写目录启动包内主程序（3.4.3 为 `JJYB-YouTube-dl_3.4.3_x64.exe`）；Windows 需要 Microsoft Edge WebView2 Runtime。
- 启动会检查便携目录、相邻 bin、托管目录和 PATH 的工具，验证身份后复用，只下载缺失项；设置中的主动检查更新与启动补齐缺失工具分开。不要删除已经可用的 FFmpeg 等组件。
- 手动升级前退出程序并备份必要配置，只替换程序及指定资源，保留当前配置与下载文件。公开分发包不得包含个人配置、Cookie、WebView 缓存或日志。

## 界面语言

在**设置 → 外观 → 语言**中手动选择简体中文、其他语言或跟随系统，保存后生效，重启后保留。界面语言与下载字幕语言独立，切换界面语言不会改变任务的字幕选轨。3.4.4 待发布源码修复了设置页工具更新成功、失败提示未使用 i18n 的问题，新增 3 项回归测试覆盖默认英文、成功和失败提示。

## 添加与下载

1. 添加有权访问的视频或播放列表 URL，等待解析；确认播放列表选中条目。
2. 选择视频或音频格式、质量、保存位置与文件名；可用质量受源站限制。
3. 按需检查字幕、封面和网络设置，再点击下载。
4. 等待下载与后处理完成，检查真实文件。同名成品会编号，配套字幕和封面沿用同一编号，不覆盖已有文件。暂停保留可续传的文件；删除未完成任务会在确认下载进程退出后清理其暂存，不删除已保存的成品。如果无法确认进程退出，应用会保留旧暂存以免损坏文件，重试时使用新的暂存目录。出错时查看任务提示与日志，不将进度当作产物验收。

## 封面下载入口

- **仅下载封面：** URL 解析后，点击任务操作区图片按钮“仅下载封面”，不需要先下载视频。该模式跳过音视频，保存独立 JPG；后端确认真实图片产物后才判成功。3.4.4 待发布源码另修复了已完成媒体的封面按钮禁用条件，组件回归测试及新版原生完成项封面重交已通过，实际核实 480×360 JPG 与旧媒体未被修改；不要将其视为已发布功能或生命周期、升级的全面验收通过。
- **随视频保存图片：** 输出设置中开启“保存封面图文件”。
- **写入媒体内部：** “嵌入封面图”是另一个选项，受容器与播放器支持限制，不等于保存独立图片。
- 图片可用性和清晰度由源站决定；没有封面或下载失败时应检查任务错误，不能把占位图当成功产物。

## 字幕

上游已具备字幕下载、语言选择、自动字幕与嵌入；本版是在其基础上增加中文优先、繁转简、仅字幕与相关修复，不是首创基础字幕能力。

- 默认 `chinesePriority` 顺序：已有简体 → 繁体下载后本地转简 → 平台中文翻译轨；同层优先人工字幕。
- 可额外选择英语、日语和韩语；任务明确选轨优先于默认策略。
- 有可用轨道时可在任务中单独勾选“下载字幕”，并检查语言和来源是否匹配。默认独立保存 SRT；普通媒体任务可同时嵌入。容器或 FFmpeg 无法嵌入时保留原媒体和独立 SRT，并在日志中提示。
- 任务字幕页“仅字幕（不下载音视频）”只生成字幕；未取得实际字幕不能判成功。
- 只提取平台已有字幕或翻译轨，不做无字幕语音识别、不调用外部机器翻译；繁简转换不是翻译。

真实 YouTube 中文翻译轨曾返回 HTTP 429，未取得该轨 SRT；后续 3.4.4 原生界面已两次下载 `jNQXAC9IVRw` 英文 SRT（416 bytes、6 段时间轴），包括已完成任务再次仅下载字幕。此前普通媒体下载返回 HTTP 403，已作为历史失败保留；最新 ready-native 普通媒体成功，详见下文，仍不能据单次成功保证网络稳定性或中文翻译轨可用。限流时停止重复请求，在正常授权环境核验；不要关闭 TLS 或绕过平台验证。

同一 ready-native 已完成 media 组补充原生复验：Preferences 中仅字幕采用默认中文优先、未选语言时，明确报告无可下载字幕；metadata 只有德语/英语，符合策略，**不是 bug**。随后手动选择人工英语（中文优先自动关闭），再次仅字幕成功；主流程实际读取 `C:\Users\李旺\Downloads\Me at the zoo-(240p15).en.srt`，为 6 段英文时间轴，范围 1.2–18.881 秒。UI 完成 100%、队列已下载 1，刚才的 1 次失败不再残留。此为新增“失败 → 重交字幕成功、计数清除”原生验收，与此前两次 SRT 和媒体 ffprobe 证据分别记录，不表示默认中文策略能生成源站未提供的轨道。

## 代理、Cookie 与隐私

网络设置可配置代理，任务可覆盖默认值。只使用自己的或获授权的 Cookie；浏览器读取受权限、状态和加密方式限制，不能保证解除平台限制。Cookie 等同会话凭据，不要公开或上传。

默认不启用 Sentry。前端需构建时配置 `VITE_JJYB_SENTRY_DSN`，后端独立读取 `JJYB_SENTRY_DSN`；启用后不保证上下文全面脱敏。关闭遥测不等于离线，媒体、封面及工具下载仍访问网络。详见[隐私说明](privacy.html)。

## 更新

应用更新只面向自有仓库最新正式稳定 Release 的 `portable-latest.json` 与 `portable-latest.json.sig`，先使用内置可信公钥验证 Ed25519 签名，再检查版本和平台；下载后校验大小、SHA256 与 Windows x64 PE，不接受同版或降级，不回退上游或跳过验签。3.4.3 正式发行已提供签名清单；资产缺失或验签失败时请手动更新。便携更新签名不是 Windows Authenticode 签名，程序仍可能显示未知发布者。

yt-dlp、FFmpeg 等工具组件更新与应用升级独立。主动更新失败应检查网络或来源，不应因此清空已可用工具。

真实隔离系统 Temp 中，官方 3.4.2 经 UI“检查更新 → 更新并重启”成功到达 3.4.3：journal `phaseCommitted`、`old_version=3.4.2`、`old_hash=bbfa958d5da20d26e92e7aa795919940881be95df37fc5bc73ed93009fc5445a`，app-ready nonce 匹配；升级后 EXE SHA256 `dd4e96d67ea49bb94421c9d9d289b2e15d0d53edeafc93323ac9dc535d7c4e18` 与官方 manifest 3.4.3 一致，“关于”显示 3.4.3。中文界面、MP4、字幕启用仍可见，但未做逐字段配置比较。仅确认 3.4.2 → 3.4.3 成功链，不等于 3.4.4 升级通过；另一次限定故障就绪回退验证见下段。

用户另行授权了隔离系统 Temp 内官方 3.4.2 → 3.4.3 的故障回退验证：watcher 独占预置普通、非 nonce 的 `app-ready` 文件，不修改官方 EXE 或签名。事务 `.jjyb-update-13831d655c884cc083b4f55ed4acc3bd` 实际经历 `Staged → Replacing → AwaitingReady → RollingBack → RolledBack`，系统 Temp 日志 `jjyb-344-rollback-watch.log` 记录后台退出码 0。恢复的 target SHA256 `bbfa958d5da20d26e92e7aa795919940881be95df37fc5bc73ed93009fc5445a` 与官方 3.4.2 一致；旧版自动重启 PID 18988，“关于”实际显示 3.4.2。已验证的仅是 3.4.2 → 3.4.3 故障就绪回退链，不等于 3.4.4 升级验收。

3.4.4 修复已完成任务点击“仅下载字幕”无响应的问题，独立封面下载共用同一修正；已完成项只参加新的字幕/封面专项动作，IPC 前转换状态，普通下载及执行快照续传仍跳过 completed。真实英文 SRT 已在原生 UI 两次通过，包括已完成任务再次提交；不能据此宣称封面或普通媒体全面通过。

## 验证范围与常见问题

本地 HTTP 样例用于验证应用能否实际生成文件、分配同名编号及续传；不代表 YouTube 等外部站点的下载、字幕或登录流程已通过。发行构建及签名状态以该版本的 GitHub Actions 与 Release 为准。

最新系统 Temp 记录：`jjyb-344-ready-unit.log` 单测 266 项/36 文件、`jjyb-344-ready-lint.log` 通过；主流程已成功执行 `jjyb-344-ready-e2e.log` 25 项及 `jjyb-344-ready-release.log` 13 项。此前 final 前端构建及 Rust 194 项、全库 rustfmt、严格 Clippy 通过记录保留为历史；此前 `jjyb-344-count-v2-native.log` 原生构建通过，最新 `jjyb-344-ready-native.log` Windows x64 原生构建通过（第 160 行 `Finished release`、第 161 行 `Built application`，退出码 0），运行验收另算。保留测试与第三方既有警告，包括 libsodium 缺失 PDB 的 LNK4099。

下载失败不增加 metadata processed/errored 计数；重交只清理相关项/组的旧诊断，保留元数据失败及已完成项。播放列表 metadata 部分失败不提前 reject 自动下载，末项 fatal 仍可 finalize；全失败保留原组 error 并 reject，不删空组；等待已 error 组立即拒绝。

本轮 3.4.3 原生真实外网测试 `jNQXAC9IVRw` 元数据成功，首次下载报 `No usable yt-dlp found`，手动重试成功。ffprobe 核验实际 MP4 为 629172 bytes、18.947483 秒、H.264 + AAC；无字幕产物，不等于字幕通过。单独工具 `--version` 连续 3 次（1534–2062 ms）及两并发（2007–2053 ms）均成功；首次原生失败根因未确定，不能猜测超时已修复。此前 `BaW_jenozKc` 返回 `This video is unavailable`，历史 HTTP 429 限制仍保留。

最新 ready-native 3.4.4 原生启动 PID 10204，本轮 `jNQXAC9IVRw` 元数据成功、单独普通媒体下载成功；UI 下载完成 100%、队列已下载 1，无旧失败计数。“在文件夹中显示”定位 `C:\Users\李旺\Downloads\Me at the zoo-(240p15).mp4`。主流程已实际运行 ffprobe（退出码 0），系统 Temp `jjyb-344-ready-media-ffprobe.json` 读到 format duration `19.000000`、size `839292`，streams 为 H.264 320×240 + AAC + bin_data + PNG 480×360（封面），无 subtitle stream；此次媒体结果不等于字幕通过，此前两次 SRT 另计。普通媒体 HTTP 403 为历史失败，不再表述为持续阻塞。
