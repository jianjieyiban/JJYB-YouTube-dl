## 获取、安装与启动

当前请使用获授权的完整源码，按[本地构建指南](../CONTRIBUTING.md)准备 Node.js、Rust 和平台依赖并构建。Windows 需要 WebView2 Runtime。自有仓库入口：[jianjieyiban/JJYB-YouTube-dl](https://github.com/jianjieyiban/JJYB-YouTube-dl)。未来安装包、支持架构和系统以该仓库实际 Release 说明为准。

不要把上游安装包、商店、Homebrew 或 WinGet 包当成本衍生版，也不要从不可信来源获取二进制文件。

- **安装版：** 有正式产物后，选择匹配系统架构的安装器，按向导安装。Tauri 更新签名不等同 Windows Authenticode 签名，不保证系统不会提示未知发布者。
- **便携使用：** 当前源码通过可执行文件同目录的 `jjyb-portable` 目录识别便携模式，数据写入该目录。使用可写目录并保留完整随附资源；仅复制一个 exe 不保证形成完整便携包。此机制不代表已提供或验收便携发行包。
- **工具组件：** 下载依赖 yt-dlp、FFmpeg 等组件。首次使用或更新组件可能需要联网，工具准备失败时先检查网络、目录权限与安全软件记录。

## 添加任务与下载

1. 从有权访问的站点复制视频或播放列表 URL，使用主界面的添加入口加入任务并等待解析。
2. 确认标题、任务数量及所需视频或音频格式。播放列表应检查实际选中条目，避免意外批量下载。
3. 在任务首选项或应用设置中检查保存目录、文件名、分辨率与容器。选择的质量仍受源站提供格式限制，不能凭空提高原视频清晰度。
4. 按需设置字幕、封面、元数据和网络选项，再开始下载。等待下载及 FFmpeg 后处理均完成后检查输出文件。
5. 下载失败时查看任务错误，针对网络、权限、组件或格式问题处理后再重试，不要把界面显示进度视为文件已完整生成。

选择音频任务时，输出格式、音质及封面支持受源媒体和转换工具限制。合并视频与音频、转换格式或嵌入内容均可能需要额外磁盘空间。

## 字幕

### 中文优先与额外语言

默认中文优先策略字段为 `chinesePriority`，按以下顺序尝试平台现有轨道：

1. 已有简体中文字幕；
2. 繁体中文字幕，下载后在本地转为简体；
3. YouTube 提供的中文翻译轨。

每层优先人工字幕；自动生成轨还受相关设置与平台可用性影响。可额外选择英语、日语、韩语。单任务明确选择的轨道优先于全局中文策略，任务结果应以实际选轨和输出文件为准。

**仅提取平台提供的字幕或翻译轨。** 没有字幕时不会对音频进行语音识别，不调用外部机器翻译服务；繁转简仅是文字转换，不是翻译，也不能保证术语和上下文完全准确。

### 普通下载与仅字幕

- 在应用字幕设置中配置默认语言及策略；在具体任务的字幕页检查可用轨道或覆盖默认设置。
- 默认保存独立 SRT。普通视频任务可选择同时嵌入字幕；容器与 FFmpeg 必须支持，不能假定每个播放器都会自动显示内嵌轨。
- 任务字幕页的“仅字幕（不下载音视频）”用于只提取字幕文件，不生成视频，也没有视频可供嵌入。
- 仅字幕任务如果没有实际下载到字幕轨，不应视为成功。检查任务错误及保存目录，不要以占位文件判断成功。
- 本地繁简转换会处理本任务跟踪到的字幕输出，不应手动把无关字幕混入任务产物。

选轨、繁简转换、仅字幕与嵌入的实现虽已加入源码，**真实 YouTube 场景仍待验收**。最新实测已解析并选中带来源后缀的中文翻译轨，但字幕请求返回 HTTP 429，尚未取得 SRT。遇到限流应停止重复请求，稍后通过正常授权环境再核验；不要关闭 TLS 校验或绕过平台验证。平台改变、权限和地区限制可能影响结果。

## 封面与元数据

输出设置中的“嵌入封面图”和“保存封面图文件”是不同选项：前者将封面写入支持的媒体文件，后者在媒体旁保存独立图片。元数据用于写入平台可提供的标题等信息。具体字段、图片质量和播放器显示取决于站点、输出格式及 FFmpeg，不保证所有格式均支持。

## 代理与 Cookie

网络设置可配置代理，任务网络选项可覆盖应用默认值。确保代理地址、协议和认证信息正确，不要将代理口令公开。

需要合法登录会话时，可在认证设置中选择 Cookie 文件或浏览器 Cookie。浏览器读取是否成功受浏览器状态、操作系统权限及加密方式影响；Cookie 不保证绕过平台访问限制，也不提供额外下载授权。

Cookie 可能等同账号会话凭据：只使用自己的或获授权的会话，不向他人提供 Cookie 文件，不上传至问题反馈、截图或代码仓库。完成排查后可移除相关配置，并按需要在平台撤销会话。

## 更新说明

### 应用更新

应用升级只面向自有仓库，固定清单目标为：

```text
https://github.com/jianjieyiban/JJYB-YouTube-dl/releases/latest/download/latest.json
```

当前配置的应用更新公钥为空，因此默认禁用应用自动更新，界面可能显示“未配置自有更新公钥”。这是安全保护，不应改成空公钥验签、跳过验签或回退上游。本次便携发行不提供自动更新清单，不能把该地址当作已上线的更新服务。

未来发布者须配置有效的配对公钥、签名产物与清单，且至少用两个真实签名 Release 完成检查、下载、验签、安装、新版启动的验证。**这条真实升级链尚未验收。**

- 安装版：仅在发布者完成上述配置与验收后，按应用提示或正式 Release 说明升级。
- 便携版：不承诺自动原地升级。退出应用，备份 `jjyb-portable` 等必要配置，按 Release 说明替换程序及随附资源，保留下载文件；不要运行中覆盖文件。
- 不要将上游更新包安装到本衍生版来“修复”更新不可用。

### 下载工具组件更新

yt-dlp、FFmpeg 等工具组件更新与应用更新是两条独立链路。设置中的工具自动更新开关不代表应用可以升级，也不会替代应用的新功能发布。组件联网更新失败应单独排查，不要因此关闭签名校验。

## 常见问题

| 现象 | 建议 |
| --- | --- |
| 解析失败、要求登录或平台拒绝请求 | 确认 URL、访问授权及网络；必要时检查自己的 Cookie，确认工具组件状态。不要反复重试或尝试规避权限限制。 |
| 没有中文字幕 | 检查平台是否提供对应字幕或翻译轨，核对中文优先与单任务覆盖；程序不会无字幕语音转写。 |
| 有视频但没有字幕显示 | 检查是否生成独立字幕、是否启用嵌入，以及播放器是否选择了字幕轨。 |
| 合并、转换或嵌入失败 | 检查 FFmpeg 可用性、输出格式、剩余空间、保存目录权限及任务错误。 |
| 目录不可写或文件名冲突 | 选择有写权限的目录，检查磁盘空间和已有文件，先备份，不要盲目删除数据。 |
| 应用更新按钮不可用 | 当前未配置公钥时属于预期状态；查看自有仓库的实际发布情况，不使用上游更新替代。 |
| 构建找不到 Stronghold 源码 | 补齐 `src-tauri/vendor/stronghold-runtime/` 并保留 Cargo 本地覆盖；不要修改依赖源码规避错误。 |

## 隐私与问题反馈

默认不启用 Sentry 遥测：前端需要构建时配置非空 `VITE_JJYB_SENTRY_DSN`（开发/E2E 模式仍跳过），后端需要启动时配置非空 `JJYB_SENTRY_DSN`；两端独立，源码不再内置上游 DSN。已配置后可能发送抽样错误、诊断上下文和性能数据，不能保证全面脱敏。

关闭遥测不代表完全离线。媒体站点、封面服务、组件来源及配置后的更新服务仍会收到必要网络请求。详见[隐私说明](privacy.html)。

反馈时提供应用版本、系统、安装/便携模式、操作步骤、实际错误及是否可复现，并区分真实站点结果与模拟测试结果。先移除 Cookie、账号、私有 URL、代理密码、个人路径等敏感信息；不要在公开问题中粘贴完整原始日志。
