# JJYB-YouTube-dl 使用文档

**版本：3.3.1 · 修改日期：2026-11-17。** 基于 [Open Video Downloader / youtube-dl-gui](https://github.com/jely2002/youtube-dl-gui)，通过 yt-dlp 下载媒体与平台字幕，使用 FFmpeg 后处理。仅下载拥有权利或已获授权的内容。

## 获取与启动

- [自有仓库与 Release](https://github.com/jianjieyiban/JJYB-YouTube-dl/releases)，实际公开资产以页面为准。本轮提供 Windows x64 本地便携程序，未构建安装器或验证其他系统。
- 保留主程序同目录的 `jjyb-portable` 和随附资源，在可写目录启动 `JJYB-YouTube-dl.exe`；Windows 需要 Microsoft Edge WebView2 Runtime。
- 启动会检查便携目录、相邻 bin、托管目录和 PATH 的工具，验证身份后复用，只下载缺失项；设置中的主动检查更新与启动补齐缺失工具分开。不要删除已经可用的 FFmpeg 等组件。
- 手动升级前退出程序并备份必要配置，只替换程序及指定资源，保留当前配置与下载文件。公开分发包不得包含个人配置、Cookie、WebView 缓存或日志。

## 添加与下载

1. 添加有权访问的视频或播放列表 URL，等待解析；确认播放列表选中条目。
2. 选择视频或音频格式、质量、保存位置与文件名；可用质量受源站限制。
3. 按需检查字幕、封面和网络设置，再点击下载。3.3.1 修复了复制响应式选项异常导致点击无反应的问题，准备阶段异常也会显示任务错误。
4. 等待下载与后处理完成，检查真实文件。出错时按任务信息排查网络、目录权限、组件和格式，不将进度当作产物验收。

## 封面下载入口

- **仅下载封面：** URL 解析后，点击任务操作区图片按钮“仅下载封面”，不需要先下载视频。该模式跳过音视频，保存独立 JPG；后端确认真实图片产物后才判成功。
- **随视频保存图片：** 输出设置中开启“保存封面图文件”。
- **写入媒体内部：** “嵌入封面图”是另一个选项，受容器与播放器支持限制，不等于保存独立图片。
- 图片可用性和清晰度由源站决定；没有封面或下载失败时应检查任务错误，不能把占位图当成功产物。

## 字幕

上游已具备字幕下载、语言选择、自动字幕与嵌入；本版是在其基础上增加中文优先、繁转简、仅字幕与相关修复，不是首创基础字幕能力。

- 默认 `chinesePriority` 顺序：已有简体 → 繁体下载后本地转简 → 平台中文翻译轨；同层优先人工字幕。
- 可额外选择英语、日语和韩语；任务明确选轨优先于默认策略。
- 默认保存独立 SRT；普通媒体任务可同时嵌入，受容器和 FFmpeg 支持限制。
- 任务字幕页“仅字幕（不下载音视频）”只生成字幕；未取得实际字幕不能判成功。
- 只提取平台已有字幕或翻译轨，不做无字幕语音识别、不调用外部机器翻译；繁简转换不是翻译。

真实 YouTube 曾成功解析并选中中文翻译轨，但请求返回 HTTP 429，未取得 SRT，**真实 YouTube 下载与字幕全链路尚未验收**。限流时停止重复请求，在正常授权环境核验；不要关闭 TLS 或绕过平台验证。

## 代理、Cookie 与隐私

网络设置可配置代理，任务可覆盖默认值。只使用自己的或获授权的 Cookie；浏览器读取受权限、状态和加密方式限制，不能保证解除平台限制。Cookie 等同会话凭据，不要公开或上传。

默认不启用 Sentry。前端需构建时配置 `VITE_JJYB_SENTRY_DSN`，后端独立读取 `JJYB_SENTRY_DSN`；启用后不保证上下文全面脱敏。关闭遥测不等于离线，媒体、封面及工具下载仍访问网络。详见[隐私说明](privacy.html)。

## 更新

应用更新只面向自有仓库 `releases/latest/download/latest.json`。当前更新公钥为空，**应用自动更新禁用，使用手动更新**；不回退上游，不跳过验签，不提供未签名清单冒充安全更新。程序未作 Windows Authenticode 签名，系统可能提示未知发布者。

yt-dlp、FFmpeg 等工具组件更新与应用升级独立。主动更新失败应检查网络或来源，不应因此清空已可用工具。未来应用自动升级仍需两个真实签名 Release 完成检查、下载、验签、安装与启动验证。

## 验证范围与常见问题

本轮修复后前端单元测试 160 项、Rust 测试 155 项、类型检查、前端构建、全库格式及严格 Clippy 检查通过；ESLint 0 错误、1 条原始中文文本警告。原生 Windows 界面使用本地 HTTP 样例验证了视频下载（H.264/AAC MP4）和独立封面（可解码 JPG）。上一轮 Edge E2E 22/22 不代表本轮复跑；本地样例不代表外网验收。第三方 Stronghold 与 libsodium PDB 既有警告保留。

| 现象 | 建议 |
| --- | --- |
| 解析失败、要求登录、429 | 确认授权和网络，按任务提示处理，不反复请求或规避验证。 |
| 点击下载报错 | 记录 3.3.1 版本、操作及任务错误，检查组件和目录权限。 |
| 找不到封面入口 | 先完成 URL 解析，再找任务操作区图片按钮。 |
| 没有中文字幕 | 检查平台可用轨与单任务选择，不支持无字幕语音转写。 |
| 视频没有显示字幕 | 检查独立字幕文件、嵌入选项及播放器字幕轨。 |
| 合并、转换失败 | 检查 FFmpeg、容器、磁盘空间及输出权限。 |
| 应用更新禁用 | 当前为空公钥的预期行为，按自有 Release 手动更新。 |
