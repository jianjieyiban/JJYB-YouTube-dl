JJYB-YouTube-dl 隐私说明

更新日期：2026-11-15。本说明适用于当前 JJYB-YouTube-dl 衍生源码的行为，不代表所有历史版本或第三方重新打包版本。项目基于 Jelle Glebbeek 等贡献者维护的 Open Video Downloader / youtube-dl-gui，本衍生版的配置与上游可能不同。

默认遥测状态

默认未配置 DSN 时不初始化 Sentry 遥测；当前源码不再内置上游 DSN。前端和 Rust 后端分别控制，不能用其中一端的状态推断另一端。

  • 前端在构建时读取 VITE_JJYB_SENTRY_DSN，仅非空且不处于开发或 E2E 模式时初始化。该值会进入前端构建产物，发行后不能仅靠删除运行环境变量撤销；需要重新构建未配置该值的版本。
  • 后端在启动时读取环境变量 JJYB_SENTRY_DSN，仅非空时初始化。前端处于开发模式不会自动关闭已配置 DSN 的后端。移除该变量后需重新启动程序。
  • 两端当前均配置错误采样率 0.25、性能采样率 0.05。这是采样配置，不代表每次必然发送，也不代表完全匿名。

相关实现位于 src/sentry.ts 和 src-tauri/src/lib.rs。SDK 依赖、日志集成与错误捕获代码的存在，不等于未配置 DSN 时已经上传数据；同样，默认不启用也不保证其他构建者没有主动配置 DSN。

主动启用遥测后可能处理的数据

配置有效 DSN 后，错误、堆栈、应用版本、运行环境、诊断上下文及抽样性能信息可能发送到该 DSN 指定的 Sentry 项目。错误或上下文可能包含下载 URL、文件路径、设置或其他个人信息；网络服务也可能接收到 IP 地址等连接信息。当前代码有部分过滤，但不保证所有事件、日志或敏感内容均已全面脱敏。

配置者应先告知使用者接收方、处理目的、保留期限和适用政策，不应默认沿用上游接收方。具体数据保留和删除取决于配置的项目及服务提供方，本文不作无依据的保留期限或删除承诺。参阅 Sentry 隐私政策。

必要网络访问与第三方服务

关闭 Sentry 不代表离线或所有数据都只在本地。解析、下载媒体和字幕时，yt-dlp 等工具会访问源站及其相关服务；显示远程封面、获取工具组件和更新时也可能访问相关服务器。请求可能包含 URL、IP 地址、必要请求头，以及你明确配置的 Cookie 或代理信息。第三方服务有各自的隐私政策，平台翻译轨也来自平台服务，而不是本地翻译。

应用更新仅指向自有仓库的 Release 清单；当前公钥为空，应用更新默认禁用。工具组件更新独立控制。截至本说明更新时尚无自有 Release，真实签名升级链未验收，不应把配置地址理解为已运行的更新服务。

本地文件、设置与 Cookie

应用会在所选目录保存下载文件，并在应用数据目录保存运行所需的配置等数据。源码识别到可执行文件同目录下的 jjyb-portable 目录时使用便携数据目录。不要假定所有本地文件、日志和备份均已加密。

认证功能支持你选择的 Cookie 文件或浏览器 Cookie。Cookie 可能携带有效账号会话，并按配置用于访问媒体站点；不应将其视为无害的匿名统计文件。仅使用自己的或获授权的会话，妥善保护相关文件，必要时在原平台撤销会话。代理地址和认证信息同样可能敏感。

日志、反馈与安全

即使未启用遥测，程序运行和排查过程中仍可能产生本地诊断输出。公开反馈前，请移除 Cookie、账号、访问令牌、私有链接、代理密码及个人路径；不要直接上传完整原始日志、配置文件或浏览器资料。任何存储或传输方式都不能保证绝对安全。

隐私问题可通过自有仓库届时实际提供的联系渠道反馈；不要向公开问题提交敏感资料。上游作者的联系邮箱不作为本衍生版的隐私联系渠道。本说明不代替对实际发行版本和部署配置的审查。
